# WebsBlocker

A lightweight browser extension designed to block distracting websites and help maintain focus during study or work sessions.

## Features
- **Custom Blocklist:** Easily add or remove distracting domains.
- **Instant Redirect / Block Page:** Prevents access to restricted sites immediately upon navigation.
- **Lightweight & Fast:** Runs quietly in the background with minimal resource usage.
- **Manifest V3 Compatible:** Built for modern Chromium-based browsers (Microsoft Edge, Google Chrome, Brave).
